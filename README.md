## 🚀 Quick Start Guide

### Option 1: Run via Google Colab *(Recommended)*

No local software setup or installation required.

1. Open [Google Colab](https://colab.research.google.com/).
2. Select **GitHub** under the Open Notebook tab and enter the repository URL:
`https://github.com/uga961/Python-Handson`
3. Launch `Class1.ipynb` and execute code blocks sequentially.

---

### Option 2: Local Execution

#### Prerequisites

Ensure Python 3.x is installed on your local environment:

```bash
python --version

```

#### Setup & Execution

1. **Clone the repository:**
```bash
git clone [https://github.com/uga961/Python-Handson.git](https://github.com/uga961/Python-Handson.git)

```


2. **Navigate into the directory:**
```bash
cd Python-Handson

```


3. **Run a script from the `Backup/` directory:**
```bash
python Backup/class1.py

```
